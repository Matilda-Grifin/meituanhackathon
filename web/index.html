自建对话页（不跳 OpenClaw）

带输入框、气泡、Markdown 图/表；后端 web_server_chat.py，逻辑与 scripts/run_local_agent.py 同源。答辩若赛题要求 OpenClaw，仍以官方网关为准；本页用于自研前端体验。

cd "D:\projects\meituan hackathon\meituan-lifecare-agent"
python -m uvicorn web_server_chat:app --host 127.0.0.1 --port 8099

打开 http://127.0.0.1:8099/。默认勾选页内 dry 需 AMAP_KEY；关 dry 需 LLM_API_KEY。

评委：一条链接进对话（不填表）

真正带输入框的对话页是 OpenClaw 自带的 Control UI（和网关同端口）。本仓库只做跳转页，避免评委看到 WebSocket / token 配置。

一键进入对话（自动跳转）

答辩 / 上云前：用编辑器打开仓库里的 judge-launch.html，把脚本里的 OPENCLAW_HOME 改成你的公网地址（例如 https://你的域名，Nginx 已反代到 OpenClaw）。需要 token 时再填 AUTH_FRAGMENT（如 #token=xxx）；关鉴权则留空。改完后把 https://你的门户/judge-launch.html 发给评委即可。

本地预览（Windows / Mac）

cd "D:\projects\meituan hackathon\meituan-lifecare-agent\web"
python serve_landing.py

浏览器打开 http://127.0.0.1:8765/（若端口占用可加 --port 8766）。本机 OpenClaw 若在跑，也可直接 http://127.0.0.1:18789/ 聊天。

阿里云：单独端口挂本门户（不影响其他项目）

  • 只把 8765（或你自定义端口）在安全组放行，不要动你其他服务占用的端口。
  • 网关日志里若飞书报错烦人，可在云上 openclaw.json 把 feishu 渠道 enabled: false，与静态门户无关。
  • 你当前日志里网关监听 ws://127.0.0.1:18789，公网浏览器不能直接连该 WS；需 Nginx 反代 WSS 或 SSH -L 18789:127.0.0.1:18789 再在本地打开 Control UI。
cd /path/to/meituan-lifecare-agent/web
python3 serve_landing.py --host 0.0.0.0 --port 8765

生产可用 systemd 保活；或用 Nginx 把 location /hackathon/ 反代到 127.0.0.1:8765，只暴露子路径。
