## 通用评测说明

每条任务采用 **rubric 逐条人工判定**，每条 rubric 判 **满足 / 不满足**，最终：

> **reward = 满足的 rubric 数 ÷ 总 rubric 数**

打分时请记录每个 rubric 的判定理由（`justification`），截取模型回复中的原文作为证据。

**全局 rubric（适用于所有任务）**：
1. Agent 是否调用了天气工具？若未调用直接扣该项。
2. Agent 是否调用了 POI 搜索工具？方案引用的 POI 是否来自工具返回（可核对名称）？
3. 方案是否同时包含玩乐/文化类与餐饮类 POI，至少 3 个可执行锚点（含正餐）？
4. 是否给出分时段安排及点间交通或路程依据？
5. 若 Agent 未完成关键约束即声称结束，相关 rubric 不判为满足。
