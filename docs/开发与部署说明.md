# 开发与部署说明

## 目录结构

| 路径 | 说明 |
|------|------|
| `lifecare/` | 配置、Redis 缓存封装、高德与天气客户端 |
| `run_mcp.py` | OpenClaw stdio MCP 入口，注册 `lifecare_*` 工具 |
| `workspace/` | 人设、模拟记忆、mock 种子、Skills |
| `gateway-chat-ui/` | React 聊天页 |
| `reference/` | OpenClaw MCP 配置片段 |
| `docs/6.3测评/` | 6.3 测评方案文档 |
| `测试/模型选型/` | 6.3 批跑脚本与 Qwen 测评结果 |
| `docker-compose.yml` | 本机 Redis（可选） |

## 环境

- Python 3.11+
- 复制 `.env.example` → `.env`，填写 `AMAP_KEY` 与模型 Key

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### Redis（可选）

```powershell
docker compose up -d
```

无 Docker 时缓存自动降级为直连 API。

## 接入 OpenClaw

1. 将 `workspace/` 复制到 OpenClaw workspace（或 `skills.load.extraDirs` 指到 `workspace/skills`）。
2. 在 `~/.openclaw/openclaw.json` 的 `mcp.servers` 增加 `reference/openclaw-mcp.snippet.json5` 中的 `lifecare` 段。
3. 重启网关后应能发现 `lifecare__lifecare_*` 工具。

## 前端

```powershell
cd gateway-chat-ui
npm ci
npm run build
```

构建产物在 `gateway-chat-ui/dist/`，由 Nginx 托管。
