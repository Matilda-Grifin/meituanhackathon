# 长期记忆（模拟数据 · 赛题要求）

以下全部为 虚构示例，不含真实用户隐私。更完整的演示用户与短评见 `mock/user_and_reviews.seed.json`（可按 `user_id` 选用）；本文件保留一条「当前会话默认」摘要即可。

重要（反问槽位）：用户只说「跟朋友玩」而未说人数时，不得把下面「朋友局 4 人」当作本轮默认；必须先问人数（选择题 D=其他自填）。仅当用户明确「我们 4 个朋友」或选定对应选项后，才可引用该条。

- 用户昵称：小明（演示账号）
- 家庭：孩子 5 岁；配偶近期饮食偏好 低油低糖。
- 朋友局（示例人设，非默认人数）：4 人（2 男 2 女），可接受微辣，偏好 咖啡+展览+小吃街。
- 常驻活动城市：杭州（演示人设 / 非 GPS 定位；用户未说城市时勿强行当成用户所在地，须用选择题让用户确认城市与所在区）
- 出行半径：单次半日行程 不超过 15km（可再确认）
- 不喜欢：长时间排队无备选方案；不接受「只有文字没有可执行下一步」
